# Disco Melo UF
## Overview
DiscoUF is a complete booking system and website created for discos held by the UF, **DISCO MELO UF**. While the disco itself no longer exists, this project serves as a portfolio piece and keepsake. It showcases a solution for managing bookings, ticketing, and venue operations.

## Features
* Booking System: Allows users to book tickets and make payments by swish whilst tracking their order number.
* Admin Panel: Provides tools for personnel to view and manage bookings and customer information.
* Check-In System: Used at the venue entrances to validate and track ticket check-ins.
* Statistics: Collects rudimentary data for analyzing the results and performance of the discos.

## Technologies Used
* Svelte: For building the frontend and admin panels.
* Socket.IO: For real-time communication between the admin client and server, this provided realtime feedback about the number of attendees.
* MongoDB: For managing the database and storing booking information, user data, and event statistics.

## Purpose
This project demonstrates the ability to build a functional system for event management, and greatly improved both the crowd flow and revenue of Disco Melo UF
